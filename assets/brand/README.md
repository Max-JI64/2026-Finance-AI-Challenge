# 버팀AI 브랜드 자산

- `buteomai-mark.svg`, `buteomai-mark.png`: 밝은 배경과 일반 문서용 심벌
- `buteomai-mark-dark.svg`, `buteomai-mark-dark.png`: 어두운 배경용 심벌
- `buteomai-logo-horizontal.svg`, `buteomai-logo-horizontal.png`: 밝은 배경용 가로형 로고
- `buteomai-logo-horizontal-dark.svg`, `buteomai-logo-horizontal-dark.png`: 어두운 배경용 가로형 로고

SVG는 크기 제한 없이 선명하게 인쇄할 때 사용한다. PNG는 HWPX, PowerPoint 등 SVG 호환성이 불확실한 편집기에 사용한다. 모든 PNG는 투명 배경이며 심벌은 1024×1024px, 가로형 로고는 1600×427px이다.

로고 주변에는 심벌 너비의 25% 이상 여백을 둔다. 심벌의 비율, 색상, 선 굵기를 임의로 바꾸거나 원화·동전·AI 반짝이 같은 추가 도형과 결합하지 않는다.
