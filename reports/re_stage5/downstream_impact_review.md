# RE Stage 5 후속 단계 영향 검토

## 최종 결정

- RE5 LightGBM Quantile은 **내부 상권환경 시나리오 생성기**로 사용한다.
- 사용자 화면에는 **하방·기준·회복**과 현금흐름 변화만 표시한다.
- P10·P50·P90, Coverage, Pinball Loss, Holdout 수치는 내부 QA에만 보존한다.
- 기존 Stage 6 이진모델은 서비스에서 제외한 상태를 유지한다.
- 모델 실패 또는 사용자가 다른 가정을 원하는 경우 직접 충격률을 사용한다.

## Holdout 한계 처리

명목 80% P10~P90 구간의 Holdout Coverage가 약 69~71%였다는 사실은 모델 개선 근거로 보존한다. 그러나 RE5 출력은 개인 매출예측, 정책 자격, 승인 가능성, 정책순위가 아니라 집계환경 시나리오의 초기값이므로 RE6 이후 구현을 중단시키지 않는다. 현재 Holdout을 보고 모델을 재선택하거나 재보정하지 않는다.

## 후속 단계 영향

| 단계 | 반영 사항 |
| --- | --- |
| RE6 | 자격 규칙과 공식 근거검색은 RE5와 독립적으로 구현한다. 모델 수치나 품질지표를 자격판정에 사용하지 않는다. |
| RE7 | 모델 내부 세 값을 하방·기준·회복 초기값으로만 받고 사용자가 직접 조정할 수 있게 한다. 개인 매출예측이나 자동 최적추천으로 표현하지 않는다. |
| RE8 | Artifact는 `src.models.re_stage5_artifact.load_re_stage5_artifact`로 읽고 실패 시 직접 충격률 입력으로 전환한다. 내부 평가 수치는 API의 사용자 응답에 포함하지 않는다. |
| RE9 | 화면은 시나리오별 현금 고갈시점·6개월 부채·이자 차이에 집중하며 모델 평가 용어를 표시하지 않는다. |

## 지연 항목

신규 상가·인허가·날씨·공휴일·문화행사 Ablation과 새로운 미래 분기 독립감사는 모델 개선 작업으로 유지한다. 이는 현재 MVP의 자격판정, 정책 금융계산, 시나리오 비교, 근거설명 구현을 막지 않는다.
