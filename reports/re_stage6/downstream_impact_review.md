# RE Stage 6 후속 단계 영향 검토

## 판정

RE6의 자격판정·근거검색·설명 안전계층은 기존 RE2 Rule·Chunk와 RE3·RE4 계산결과의 의미를 변경하지 않는다. Gate RE6을 통과하며 RE7 정책 개입안 비교를 시작할 수 있다.

## RE7 전달 계약

- 자격결과: `입력 기준 적격 후보`, `부적격`, `추가 확인 필요`
- 접수상태: `기준일상 접수 가능`, `접수기간 종료`, `접수 가능 여부 확인 필요`
- 정책 버전·기준일·통과/실패/미확인 Rule ID
- 공식 공고 URL·신청 URL·최종 기관 확인 문구
- RE4가 계산한 현금흐름·부채·이자 값은 Fact-lock 상태로 설명계층에 전달

사용자는 다음 전달계약을 승인했다. `입력 기준 적격 후보 + 기준일상 접수 가능`은 `지금 비교 가능`, `추가 확인 필요` 또는 접수상태 확인이 필요한 정책은 `확인 후 비교`, `부적격` 또는 접수기간 종료 정책은 `제외`로 분류한다. 조건부 정책은 사용자의 명시적 가정이 있을 때만 계산하고 기본 1순위·빠른실행 1순위에서 제외한다. `입력 기준 적격 후보`도 승인 가능성을 뜻하지 않는다.

2026-08-16 최종 RE7 계약에서 정책 조합은 `조합 가능·확인 필요·조합 불가`로 관리하고 확인된 조합만 기본 비교에 포함하도록 확정했다. 13주는 RE5 Target A, 6개월은 Target B를 기본 100% 참고 기준으로 적용하되 사용자 조정·직접 충격률을 허용한다. 안전현금은 향후 4주 필수지출로 계산한 수정 가능한 제안값이며, 입력이 부족하면 임의 정액을 만들지 않는다. 이 계약은 문서에만 반영했고 RE7 구현은 시작하지 않았다.

## RE8·RE9 전달 계약

- 세션 자격 프로필 원값은 로그·DB·검색 인덱스에 저장하지 않는다.
- 정확한 신용점수는 받거나 저장하지 않고 NCB 임계값 이하 여부만 사용한다.
- 사용자 화면에는 판정 이유와 공식 근거를 쉬운 문장으로 보여주되 Rule ID·검색점수·BM25 같은 내부 세부사항은 숨긴다.
- RAG 또는 설명 실패 시 기존 계산값과 공식 링크는 유지한다.
- 생성형 설명이 계산값·자격상태·정책순위를 바꾸면 응답을 폐기한다.

## 변경되지 않은 항목

- RE5 LightGBM Target·Artifact·시나리오 출력
- RE3 현금흐름 계산식
- RE4 금융 Event·상환 계산
- 기존 Stage 6 서비스 제외 상태

외부 LLM은 이번 Stage에서 호출하지 않았다. `SafeExplanation` 스키마와 검증기는 향후 LLM을 연결하더라도 잠긴 계산·자격·근거 밖의 값을 받아들이지 않는다.
