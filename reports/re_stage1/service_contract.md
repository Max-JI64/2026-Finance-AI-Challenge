# RE Stage 1 서비스 계약

## 승인 상태

- 승인일: 2026-08-15
- 승인 내용: 기존 Stage 0~6을 보존하고 `서울 소상공인 정책효과 시뮬레이터`로 전환
- 정책 범위: 최종 8~12개
- 정책 선정 방식: A·B·C·A+C·A+B·A+B+C의 비교용 후보안을 먼저 검토하고, 최종 목록은 별도 사용자 승인으로 확정
- 현재 최종 정책 목록: 미선정

## 서비스 문제

서울 소재 소상공인이 아무 정책도 이용하지 않을 때와 보조·비용지원·이차보전·대환·융자·복합 정책을 이용할 때의 현금잔액, 현금 고갈 시점, 신규부채와 상환의무를 같은 시간축에서 비교한다.

## 사용자와 지역

- 대상: 서울에서 영업 중인 소상공인
- 지역 데이터: 서울 상권×업종 집계환경
- 정책 범위: 서울 소재 사업자가 검토할 수 있는 전국 정책과 서울 정책
- 실제 신청·승인·대출 실행: 서비스 범위 밖

## 입력 계약

- 간편 입력: 월매출, 주요 고정비·변동비, 현재 현금, 기존 대출의 월 상환액, 예상 충격률
- 상세 입력: 표준 CSV의 날짜별 또는 월별 현금 유입·유출·부채 일정
- 입력 저장: 세션 내 계산 우선
- 계좌·카드·POS 자동연동: 제외

## 계산 범위

- 기준선: 무대응 시나리오 필수
- 단기: 13주 주별 현금흐름
- 중기: 6개월 월별 현금흐름
- 기본 목표: 최소부채로 안전현금 회복
- 선택 목표: 최장생존, 최소상환, 빠른실행
- 안전현금 기준: RE Stage 3에서 사용자 입력값과 설명 가능한 기본값 후보를 비교한 뒤 승인

## 서비스 출력

- 13주·6개월 현금잔액 곡선
- 최저 현금잔액과 현금 고갈 예상 시점
- 신규 차입액, 월 원리금, 총이자와 총상환의무
- 정책 지원금·비용감면액과 지급 지연 영향
- 공식 자격 판정과 미확인 조건
- 정책별 공식 근거, 신청기한, 실행순서
- 사용자 목표별 대안 비교

## 역할 분리

| 구성요소 | 허용 역할 | 금지 역할 |
| --- | --- | --- |
| ML | 상권×업종 집계환경 시나리오 | 개인 폐업·부도·신용·승인확률 예측 |
| 규칙 엔진 | 공식 조항 기반 자격판정 | 추정 자격 확정 |
| 현금흐름 엔진 | 금액·날짜·상환 계산 | LLM 계산값 채택 |
| 비교 엔진 | 승인된 목표별 대안 비교 | 근거 없는 정책 순위 변경 |
| RAG | 공식 정책 근거 검색 | 비공식 요약을 최종 근거로 사용 |
| LLM | 근거와 Trade-off 설명 | 자격·금액·순위 계산 변경 |

## 폐기·동결 계약

- 기존 금융부담 0~100점과 20/20/35/25 가중치는 구현하지 않는다.
- 낮음·주의·높음 등급과 단순 정책 적합도 백분율·1~3위 Ranking은 사용하지 않는다.
- 기존 Stage 0~6은 삭제하지 않고 해시와 함께 기준선으로 동결한다.
- Stage 6은 최종 핵심 출력이 아니라 보조·Fallback 후보로 둔다.
- 기존 Stage 7~12 실행은 RE Guard로 차단한다.

## 단계 종료 후 환류 규칙

각 Stage의 필수 Gate와 산출물 검증이 끝나면 다음 Stage를 바로 시작하지 않는다. 먼저 결과가 후속 단계의 가정·데이터 포함범위·Target·Feature·모델·평가지표·서비스 범위·일정을 바꾸는지 검토한다. 변경이 없으면 `변경 없음`과 근거를 기록하고, 변경이 필요하면 영향받는 계획서·체크리스트·설정·테스트를 수정한다. 결과 의미를 바꾸는 수정은 사용자 승인을 받은 뒤 반영하며, 이 검토가 끝나기 전에는 다음 Stage를 시작하지 않는다.
