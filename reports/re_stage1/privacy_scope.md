# RE Stage 1 개인정보 처리범위

## 기본원칙

- 회원가입 없는 샘플 모드와 세션 내 계산을 우선한다.
- 금융 계산에 필요하지 않은 개인식별정보는 수집하지 않는다.
- 실제 원금액을 애플리케이션 로그와 분석 로그에 남기지 않는다.
- 외부 LLM에는 정책 근거와 비식별 계산 요약만 전달한다.

## 필드별 처리계약

| 정보 | 입력 허용 | 영구저장 기본값 | 외부 LLM 전송 | 비고 |
| --- | --- | --- | --- | --- |
| 상권·업종 | 허용 | 비저장 | 필요 시 허용 | 집계환경 조회용 |
| 월매출·비용 | 허용 | 비저장 | 원금액 금지 | 로컬 계산 엔진 사용 |
| 현재 현금잔액 | 허용 | 비저장 | 금지 | 세션 내 계산 |
| 대출잔액·금리·상환액 | 허용 | 비저장 | 원금액 금지 | 금융 이벤트 계산 |
| 사업 개월 수·종업원 수 | 허용 | 비저장 | 최소화 | 자격 규칙에 필요할 때만 |
| 사업자등록번호 | 필수화 금지 | 저장 금지 | 금지 | 공식 조회 연동도 MVP 제외 |
| 주민등록번호 | 수집 금지 | 저장 금지 | 금지 | 입력 UI에도 두지 않음 |
| 계좌번호·카드번호 | 수집 금지 | 저장 금지 | 금지 | 자동연동 제외 |
| 개인 신용점수 | 수집 금지 | 저장 금지 | 금지 | 신용평가 서비스가 아님 |
| 자유서술 | 최소화 | 비저장 | 비식별 후 제한 | 민감정보 입력 경고 |

## 로그 허용범위

- 요청 ID, 실행시각, 계산 엔진 버전, 정책 데이터 버전
- 성공·실패 상태와 오류유형
- 원금액을 제거한 구간값 또는 테스트용 합성값
- 사용자 동의 여부와 데이터 삭제 완료 상태

## 금지범위

- 명시적 동의 없는 영구 저장
- 원본 CSV의 서버 장기보관
- 개인 입력과 외부 공공데이터를 이용한 신용·부도·폐업확률 산출
- 정책 신청대행 또는 실제 대출 실행
