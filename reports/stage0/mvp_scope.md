# Stage 0 — MVP 포함·제외 범위

기준일: 2026-08-14  
근거: `프로젝트 계획서.md`의 38~41절, `MVP 단계별 구현 체크리스트.md`의 단계 0

## 포함 범위

| 구분 | MVP 구현 내용 | 경계 |
| --- | --- | --- |
| 대상 | 서울특별시 내 소상공인 | 전국 단위로 일반화하지 않음 |
| ML 예측 | 다음 분기 `상권 × 업종` 매출환경 악화 위험 | 개별 점포의 폐업·부도 확률이 아님 |
| 검증 | 시간순 Train/Validation, Logistic Regression과 LightGBM 비교 | 랜덤 분할 성능을 대표 결과로 사용하지 않음 |
| 금융진단 | 사용자가 입력한 매출·임대료·인건비·대출 정보를 이용한 부담 지표 | 실제 신용정보나 은행 내부정보를 사용하지 않음 |
| 종합진단 | 외부 상권환경 위험과 내부 금융부담을 별도 값으로 제시 | 두 값을 근거 없이 하나의 확률로 합치지 않음 |
| 정책추천 | 명시적 조건 필터 후 재현 가능한 적합도 Ranking | 정책 적격성 판단을 LLM에 전적으로 맡기지 않음 |
| RAG | 공식 정책자료를 검색해 조건·한도·신청방법을 근거와 함께 설명 | 근거가 없으면 `확인 불가` 또는 `확인 필요`로 반환 |
| 서비스 | 입력부터 진단·추천·설명까지 이어지는 배포 웹서비스 | 실제 대출 실행이나 정책자금 신청대행은 하지 않음 |

## 제외 범위

- 전국 상권 예측
- 개인 신용평가 또는 신용점수 자동조회
- 개인·사업체 부도확률 예측
- 실제 점포 폐업확률 예측
- 대출 승인 가능성 예측 또는 금융기관 대출심사 대행
- 은행계좌, 카드매출, 금융기관 내부 데이터 연동
- 실제 대출 실행 및 정책자금 신청대행

## 공통 설명 문구

> 이 서비스의 상권위험 점수는 개별 점포의 폐업확률이나 대출 승인 가능성이 아니라, 서울시 상권·업종의 다음 분기 매출환경 악화 위험을 나타냅니다. 금융부담 진단은 사용자가 입력한 값에 기반한 참고 정보이며 금융기관의 심사나 확정적 금융판단을 대신하지 않습니다.
