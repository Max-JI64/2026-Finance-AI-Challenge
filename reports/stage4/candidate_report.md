# Stage 4 단일 분기 Target 후보 비교 — 대체됨

- 상태: 2026-08-14 사용자 결정으로 **향후 2개 분기 지속 악화 Target 분석으로 대체됨**
- Target 시점: Feature 분기의 실제 다음 분기
- 변화율: `(다음 분기 매출 - 다음 분기의 전년 동기 매출) / 다음 분기의 전년 동기 매출`
- 미래정보 누수 방지: 분위수 기준을 선택할 경우 학습 기간에서만 임계값을 Fit해야 한다.

## 생성 가능 행

- 실제 다음 분기가 있는 행: 406,787
- 다음 분기의 전년 동기까지 있는 행: 329,169
- 전년 동기 매출 0으로 비율 계산이 불가능한 행: 0
- 최종 후보 비교 가능 행: 329,169
- Target 기간: 20221~20254
