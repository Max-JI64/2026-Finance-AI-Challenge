# RE Stage 8.3 사용자 직접 서비스 검토·수정 원장

## 현재 상태

- 단계 상태: 진행
- 외부 배포: 중단
- 검토 방식: 사용자가 로컬 서비스 화면을 직접 확인
- 스크린샷·이미지 분석: 수행하지 않음

## 변경 이력

- `RE8.3-001` 접수: 사용자 브라우저 주석 1~6번과 8번을 3단계 현금 진단 화면 개선으로 묶었다. 주석 7번의 조건부 정책 가정 체크박스는 실제 비교 범위를 바꾸는 기존 계약이므로 동작을 설명하고 이번 수정에서는 유지한다.
- `RE8.3-001` 구현·자동검증: `app/static/index.html`, `app/static/styles.css`, `app/static/app.js`, `tests/test_re_stage8.py`를 변경했다. 기준자료 표시를 제거하고 선택 목적 문구, 숫자 전용 KPI 강조, 6개월 현금 숫자 강조, 선·범례 범위 선택, 명시적 `0만원` 경계, 이름이 표시된 안전현금 영역, 안전현금 상단 점선 제거, `재무 입력 수정` 명칭을 반영했다. 일반 Python 3.13 집중 테스트 29개, JavaScript 문법, 변경 파일 공백 검사가 통과했으며 모델·계산·조건부 정책 계약은 바꾸지 않았다. 최종 시각 판정은 사용자 재확인 대기다.
- `RE8.3-001` 후속 요청: 조건부 정책 가정 설정을 결과 상단으로 이동하고, 짧은 요약과 `무엇이 달라지나요?` 상세 팝업을 제공한다. 잘못 입력된 발표용 빠른 시연 문장은 요청이 아닌 것으로 정정해 원장과 인계에서 제거한다.
- `RE8.3-001` 후속 구현·자동검증: 조건부 정책 설정을 KPI 위로 이동하고 `조건이 맞는다고 가정해 현금 영향만 비교하며 추천 순위에는 포함하지 않는다`는 요약을 표시했다. 상세 팝업은 체크 시 계산 범위, 체크 해제 시 제외 범위, 자격·승인 비확정 주의를 구분해 설명한다. 기존 기본 체크 상태와 `assume_conditional` 계산 계약은 유지했다. 집중 테스트 29개, JavaScript 문법, 변경 파일 공백 검사가 다시 통과했다.
- `RE8.3-001` 캐시 결함 확인·수정: 새 HTML은 반영됐지만 버전 없는 정적 링크로 이전 CSS·JavaScript가 남아 팝업 무반응과 KPI 파란 배경이 재현됐다. `/static/styles.css?v=re8.3-001.2`, `/static/app.js?v=re8.3-001.2`로 갱신하고 `/`·`/static/` 응답에 `Cache-Control: no-store`를 적용했다. 실제 `127.0.0.1:8000` 응답에서 최신 KPI 규칙·팝업 Listener·헤더를 확인했고 집중 테스트 30개, JavaScript 문법, 공백 검사가 통과했다.
- `RE8.3-001` 필수 결정 대기: 3단계에는 정책 설명이 없으므로 조건부 정책 설정을 제거하고 `assume_conditional=false`를 기본으로 고정하는 안을 권장한다. 이는 조건부 정책이 4단계 자격 확인 전 현금 계산과 대안 카드에서 제외되는 결과 범위 변경이므로 사용자 승인 전에는 적용하지 않는다. 대안은 설정을 4단계 정책 후보 영역으로 이동하고 기본값만 false로 두는 것이다.
- `RE8.3-001` B안 승인·후속 구현: 사용자 승인에 따라 조건부 정책 설정을 3단계에서 제거하고 4단계 정책 후보 영역으로 이동했으며 기본값을 `assume_conditional=false`로 바꿨다. 선택 시에만 미확정 정책 효과를 별도 가정하고 추천 순위에는 넣지 않는 설명과 팝업을 제공한다. 3단계는 불필요한 KPI 보조문구를 제거하고 `안전현금 아래`를 `현금 부족 예상` 시점으로 교체했다. 그래프 바로 위에 노란 안전현금 요약·상세 팝업을 두고, 그래프 선·범례·범위 카드에 호버 피드백을 추가하며 십자 커서를 제거했다. 첫 비교 때 하방·기준·회복 API 결과를 병렬 계산해 보관하고 이후 범위 선택은 추가 API 호출 없이 즉시 전환한다. 정적 자산 버전을 `re8.3-001.3`으로 올렸고 실제 `127.0.0.1:8000` 응답에서 `no-store`, 새 UI·호버 CSS·세 범위 캐시 JavaScript·구형 문구 제거를 확인했다. 일반 Python 3.13 집중 테스트 30개, JavaScript 문법, 변경 파일 공백 검사가 통과했다. 앱 내 브라우저 자동 제어는 신뢰 경로 오류로 수행하지 못해 최종 시각 판정은 사용자 재확인 대기다.
- `RE8.3-002` 접수·범위 판단: 4단계 주석 6건을 묶었다. `대회개요.md`의 금융 현안·맞춤형 금융서비스 기준과 현재 정책 Event를 대조해, 사업체 현금·부채에 직접 연결되지 않는 병원 생활비·민간 돌봄·공제 적립·6개월 밖 효과·접수 종료·금융조건 미확정 정책은 기본 노출에서 제외하되 원본 17개 정책 DB와 검수 자산은 보존하기로 했다. 이미지 분석은 주석 텍스트만으로 충분해 수행하지 않았고 contact sheet도 생성하지 않았다.
