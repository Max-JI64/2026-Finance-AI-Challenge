# RE Stage 9 최종 QA 보고서

## 판정

**로컬 제출준비 QA 통과 / Gate RE9 미통과**

외부 공개 URL, 제출기간 접근, 운영계정 Usage tier·API 키와 공개 URL 재시작 검증은 사용자 배포 결정 전이라 완료하지 않았다. 이를 제외한 로컬 기능·수치·검색·개인정보·문서 준비 항목은 통과했다.

## 자동 QA

- 가상 페르소나: `8/8`
- 대표 10개 정책 검색: `20/20 Hit@5`
- 금지된 긍정 주장: `0건`
- 부분대환: 기존 8,000만원 중 5,000만원 대환, 순신규차입 0원
- Embedding 장애: 최대 2회 뒤 `bm25_fallback`
- 잘못된 입력: HTTP 422, 입력 원문 비반사
- 그래프 마지막 현금과 요약값: 8개 모두 일치
- 내부 Rule ID·Chunk ID·검색점수 응답 노출: 0건
- 스크린샷 이미지 분석: 미실시
- Docker 이미지 Build: 로컬 Docker CLI 미설치로 미검증
- 브라우저 DOM 재검증: 자동화 브라우저 미연결로 미검증, API·HTML·CSS 자동검사만 통과

상세 입력·결과·Trace는 `persona_oracle.json`, `persona_summary.csv`, `retrieval_20_cases.csv`에 보존했다.

## 개인정보·보안

- `.env`는 Git과 Docker 빌드에서 제외한다.
- 컨테이너는 비루트 사용자로 실행한다.
- 로그 계약은 경로 Template·상태·처리시간·Fallback 여부만 허용한다.
- 요청 본문, 원금액, 자격 응답, 질문, 키와 외부 API 본문은 로그 금지다.
- 입력을 서비스 DB·검색 DB·브라우저 저장소에 영구 저장하지 않는다.

## 남은 필수 Gate

1. 사용자가 배포 플랫폼·계정·비용 책임을 선택하고 외부 배포를 승인한다.
2. 공개 URL과 제출기간 접근성을 확인한다.
3. 운영계정 Usage tier·운영 API 키·5초 Timeout·최대 2회·BM25 Fallback을 확인한다.
4. 공개 URL 재시작 뒤 P01·P03·P08을 재현한다.
5. 공개 URL의 데스크톱·모바일 DOM·오버플로 QA를 수행한다.
6. 데모 직전 10개 정책의 접수상태·변경공고·공식 링크를 다시 확인한다.
