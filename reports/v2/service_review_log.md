## 변경 이력

- `V2-001` 접수·구현: 첫 화면 Hero의 내부 AI 역할 3칸과 전용 CSS를 제거했다. 화면 결과의 최종 판정은 사용자가 직접 수행한다.
- `V2-002` 접수·구현: 다섯 시연을 강남 마이스 관광특구, 대학로(혜화역), 이태원 관광특구, 성수동카페거리, 노량진역(노량진)에 각각 배정했다. 기존 시연별 재무 입력값과 한식업 코드는 유지했다.
- `V2-001`·`V2-002` 내부 검증: 다섯 상권 코드와 자치구가 모두 고유하고 각 상권의 `CS100001` 시장 전망 API가 `available=true`를 반환했다. 관련 Python 회귀 53개, JavaScript 문법, 공백 검사가 통과했다. 화면 표시와 시각 결과는 검증하지 않았으며 사용자 확인 대기다.

- `V2-012` 문서화: 계획표에 전체 화면·기능·파일·함수·API·데이터 근거, 정책 17/11/6/3과 조건부 그래프 4·상세 Event 3의 구현 깊이, AI와 결정론 엔진 역할, 사용자 행동별 상태 변화, 대회 목적·AI 강화 재비교 기준, 현행 구조의 한계를 추가했다. 현재 로컬 비교 API가 LightGBM 시나리오를 사용하면서 정책 검색은 `bm25_fallback`임도 확인해 실시간 AI 실행 범위를 과장하지 않도록 기록했다. 서비스 코드·계산·정책·데이터·화면은 변경하지 않았다.

## V2 검토 원칙

- 각 요청은 `V2-001`부터 순서대로 관리한다.
- 화면의 표시·배치·가독성·최종 시각 결과는 사용자가 직접 판정한다.
- Codex는 내부 데이터 유효성, API 응답, 계산·상태 변경 계약과 코드 회귀만 확인한다.
- 결과 의미·정책 범위·자격 기준·추천 순위·외부 전송을 바꾸는 선택은 구현 전에 사용자 승인을 받는다.
