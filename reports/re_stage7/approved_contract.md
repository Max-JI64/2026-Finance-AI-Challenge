# RE Stage 7 최종 승인 계약

## 상태

- 계약 버전: `re7-contract-v1`
- 승인일: 2026-08-16
- 계약 상태: 승인 완료
- 구현 상태: 2026-08-16 사용자 재개 요청에 따라 `re7-v1` 구현·Gate 통과

## 사용자 표시와 후보 처리

자격판정과 현재 접수상태는 내부에서 별도로 보존한다. 사용자에게는 `지금 비교 가능`, `확인 후 비교`, `제외`만 보여준다. `확인 후 비교` 정책은 사용자가 조건 충족을 명시적으로 가정한 경우에만 계산하며 기본 1순위와 빠른실행 1순위에서 제외한다.

## 정책 동시수혜·중복지원

정책 조합은 다음 세 상태로 관리한다.

| 상태 | 의미 | 기본 처리 |
| --- | --- | --- |
| 조합 가능 | 공식 근거로 동시 적용 가능이 확인됨 | 기본 복합안에 포함 가능 |
| 확인 필요 | 공식 근거가 없거나 기관 확인이 필요함 | 사용자 명시적 가정이 있을 때만 조건부 비교 |
| 조합 불가 | 중복지원 금지 또는 같은 지출을 중복 보전함 | 조합에서 제외 |

확인되지 않은 조합을 자동으로 허용하지 않는다. `확인 필요` 조합은 기본 1순위와 빠른실행 1순위가 될 수 없다.

## 상권환경 시나리오 적용

- 13주 계산에는 `target_a_next_quarter_yoy`를 사용한다.
- 6개월 계산에는 `target_b_next_two_quarter_yoy`를 사용한다.
- 기본 적용률은 100%다.
- 기본 결과는 `상권환경 변화율을 동일 비율로 반영한 참고 스트레스 계산`으로 표시한다.
- 사용자는 적용률을 조정하거나 직접 충격률로 덮어쓸 수 있다.
- 선택한 적용률과 가정을 결과에 기록한다.
- 결과를 개인 점포의 실제 매출예측으로 표현하지 않는다.

100%는 개인 점포에 동일 변화가 발생한다는 통계적 주장이 아니라, 숨은 임의계수 없이 모델 변화율을 그대로 사용하는 투명한 참고 기준선이다.

## 안전현금

안전현금 권장값은 `앞으로 4주 동안 반드시 지급해야 하는 비용`으로 계산하고 사용자가 수정할 수 있게 한다.

- 상세 입력: 향후 28일의 임대료·인건비·공과금·세금·대출상환·필수 매입 등 필수 지출 일정 합계
- 간편 입력: 월 고정비 + 월 대출상환액 + 필수 변동비 추정액
- 필요한 입력이 부족하면 임의 정액을 만들지 않고 사용자 직접 입력을 요청
- RE3의 사용자 입력 우선·임의 기본값 금지 원칙은 유지

## 구현 이력

이 문서는 먼저 결과를 바꾸는 RE7 의사결정 계약만 확정했고 당시에는 구현하지 않았다. 2026-08-16 사용자의 `RE 7을 진행해줘` 요청으로 구현 권한이 새로 부여되어 비교·정렬·Pareto·실행계획 엔진, 상세 가상 표본, 테스트와 Gate 증거를 만들었다. 웹 화면과 API 연결은 RE8 범위로 남기며 계약 의미는 변경하지 않았다.
