# RE Stage 7 검증 결과

## 판정

Gate RE7은 통과했다. `re7-v1`은 무대응을 자동 포함하고 RE3 상세 현금흐름, RE4 정책 금융 이벤트, RE5 상권환경 변화율, RE6 자격·접수 상태를 같은 13주·6개월 비교 계약으로 결합한다.

## 구현 범위

- 후보 라우팅: `지금 비교 가능`, `확인 후 비교`, `제외`
- 조합 판정: `조합 가능`, `확인 필요`, `조합 불가`; 공식 근거가 없는 정책쌍은 Fail-closed로 `확인 필요`
- 대안: 무대응, 비용절감, 사후정산 보조, 대환, 신규 운영자금, 조건부 복합안
- 지표: 13주·6개월 현금, 최저현금, 고갈일, 순신규차입, 대환원금, 월 최대 원리금, 만기 총이자, 총상환의무, 지원·절감액, 지급지연, 신청마감, 확인항목 수
- 목표: 최소부채, 최장생존, 최소상환, 빠른실행을 임의 가중합 없이 사전식 정렬
- Pareto: 기본 정렬 가능한 대안 사이에서만 지배관계 계산
- 실행계획: 지금 확인할 조건, 마감일, 서류, 지급 전 필요현금, 실패 시 대안, 최소대출, 문의처와 공식 URL

## 대표 산출물 QA

- 동결 상세 가상 표본: 3개
- Hero 대안: 무대응 포함 6개, 계산 6개
- 기본 정렬 가능: 2개; 현재성·동시수혜 확인이 필요한 조건부 계산: 4개
- 동시 표시 계약: 무대응·비차입·신규자금·복합안 4개; 비용절감·대환은 토글 ID로 분리
- 13주 생존: 일말 현금잔액 0원 이상 유지기간이며 실제 존속·폐업 예측과 분리
- 공식값·사용자값·명시적 가정·계산값 출처가 assumption ledger에 공존
- `fit_percentage`, 승인확률, 개인 매출예측, 정책 인과효과, AI 최적 정책 출력 필드 없음
- 대표 결과와 입력·보고서 SHA-256은 `reports/re_stage7/manifest.json`에 기록

## 대표 결과의 정직한 한계

Hero의 Track2·대환·서울 긴급자금은 기준일 현재 잔여예산 또는 접수상태 재확인이 필요해 모두 `확인 후 비교`다. 따라서 정책 대안은 명시적 가정으로 현금·부채 효과를 계산했지만 기본 1순위에는 포함하지 않았다. 기본 정렬 가능한 무대응과 비용 5% 절감은 모두 13주를 버티지 못해 목표별 결과가 생존일 Fallback을 사용했다. 이는 Gate 실패가 아니라 최신 접수상태와 자격을 임의로 확정하지 않은 결과다.

웹 화면, 실제 토글 상호작용, API 연결과 모바일·데스크톱 표시는 RE8에서 검증한다.
