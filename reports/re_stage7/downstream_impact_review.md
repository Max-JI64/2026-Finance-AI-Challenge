# RE Stage 7 후속 단계 영향 검토

## 판정

RE7 결과는 승인된 계약과 일치하며 RE3 계산식, RE4 정책 이벤트, RE5 Target·Artifact, RE6 Rule·RAG 의미를 변경하지 않는다. Gate RE7을 통과하며 RE8 API·웹 통합을 시작할 수 있다.

## RE8 전달 계약

- API는 `DecisionResult`의 기준일, 엔진 버전, 후보상태, 조합상태, 13주·6개월 지표, 목표별 정렬, Pareto, 실행계획, 가정 원장과 공식 URL을 전달한다.
- Hero 기본 곡선은 `no_action`, `track2_reimbursement`, `emergency_loan`, `combined_safe_cash` 최대 4개다. `cost_reduction_5`와 `refinance`는 토글로 전환한다.
- `확인 후 비교`는 사용자 가정이 있을 때만 계산하며, 계산하더라도 기본 1순위와 빠른실행 1순위에 들어가지 않는다.
- Rule ID·Chunk ID·BM25 점수·검색순위는 RE7 사용자 결과에 없으며 RE8도 노출하지 않는다.
- 13주는 Target A, 6개월은 Target B를 독립 적용한 참고 스트레스 계산으로 표시하고 개인 점포 매출예측이라고 부르지 않는다.
- 상세 일정 표본만 정확한 Hero 주차 데모에 사용한다. 월 금액 간편 입력은 RE8의 승인된 초·중·말 일정 Wrapper가 구현될 때까지 정확한 주차 결과로 표시하지 않는다.
- 안전현금 직접 수정 입력과 실제 화면 토글은 RE8에서 연결한다.

## RE9 전달 계약

- 현재 3개 상세 표본은 Hero와 회귀 QA용이며, RE9의 고정 가상 페르소나 8개 정답 계약을 대체하지 않는다.
- 데모 직전 10개 정책의 접수상태·변경공고·공식 링크를 사용자가 내려받아 갱신한 자료로 재확인해야 한다.
- 조건부 정책 결과를 실제 승인·수혜·효과 증거로 발표하지 않는다.

## 변경되지 않은 항목

- Target·Feature·학습·검증기간·모델 선택·평가 지표
- 대표 10개 정책 범위와 공식 원문
- RE3·RE4 금융 계산 계약
- 세션 자격 프로필 비저장과 외부 LLM 미호출

새 외부 데이터 수집이나 다운로드는 수행하지 않았다.
