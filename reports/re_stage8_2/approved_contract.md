- Timeout: 요청당 5초

## 외부 전송 범위

후보발굴 Embedding에는 자치구명, 업종 대분류, 매출추세 구간, 고정비 부담 구간, 부채 부담 구간, 현금위험 구간, 사용자 목표만 전송한다. 정책 자유질문은 로컬 정규식으로 금액·전화번호·사업자등록번호·계좌형 번호·주민등록번호·상호명 표기·상세주소 패턴을 제거한 문자열만 전송한다.

원금액, 상호명, 상권명, 상세주소, 주민등록번호, 사업자등록번호, 계좌번호, 자격질문 원답은 Embedding 후보발굴 문장에 포함하지 않는다. 입력·질문·Embedding 응답은 서비스 DB, 검색 인덱스, 브라우저 저장소와 애플리케이션 로그에 영구 저장하지 않는다.

OpenAI API 데이터는 기본적으로 모델 학습에 사용되지 않는다. 다만 기본 악용 모니터링 로그에는 최대 30일 포함될 수 있으며, Zero Data Retention은 별도 승인 대상이다. 근거는 [OpenAI API 데이터 제어 문서](https://developers.openai.com/api/docs/guides/your-data#default-usage-policies-by-endpoint)를 따른다.

## 비용과 Rate limit

`text-embedding-3-large` 공식 가격은 입력 100만 Token당 USD 0.13이다. 예를 들어 100 Token 질의 1회는 약 USD 0.000013이고, 오류 재시도까지 2회 발생하면 약 USD 0.000026이다. 실제 Token 수와 청구액은 요청 문장과 계정 사용량에 따라 달라진다. 근거는 [OpenAI 모델 문서](https://developers.openai.com/api/docs/models/text-embedding-3-large)이다.

Rate limit은 계정 Usage tier에 따라 달라지므로 특정 RPM/TPM을 고정 가정하지 않는다. 429, 5xx, 연결·Timeout·응답 파싱 오류만 한 번 재시도한다. 400·401 등 재시도로 해결되지 않는 오류는 즉시 BM25로 전환한다.

## 자격질문과 계산 경계

공통 1차 질문은 기업 규모, 개업일, 상시근로자 수, 영업 여부다. 후보별 추가 질문은 해당 정책의 공식 조건에 필요한 항목만 `예/아니오/모름`으로 표시하며 질문 이유와 결과 영향을 함께 보여준다. `모름`은 부적격으로 바꾸지 않고 `추가 확인 필요`로 유지한다.

기존 10개 정책은 동결된 RE6 Rule을 사용하고, 검색 전용이던 7개 정책은 별도 RE8.2 검수 Rule overlay를 사용한다. 검색 점수와 Luna는 자격, 현금계산, 순위를 바꾸지 못한다. 사업체 현금 Event가 검수되고 사용자가 실제 금액·일정을 입력한 고용보험료 환급과 가족친화 기업지원금만 동적 대안으로 연결한다. 이음공제, 노란우산 적립, 입원 생활비, 민간 아이돌봄과 접수 종료된 중구 지원은 각 효과의 성격·기간·접수상태 때문에 사업체 6개월 가용현금 대안으로 승격하지 않는다.
