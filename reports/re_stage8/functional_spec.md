# RE Stage 8.1 기능명세서

## 사용자 흐름

1. `사업장 선택`: 지도에서 서울 전체→자치구→행정동→개별 상권으로 좁히거나 목록에서 상권을 고르고, 업종 대분류→세부 업종과 영업기간을 선택한다. 발표용으로 가게 상황 5종을 한 번에 입력·계산하는 빠른 시연을 제공한다.
2. `재무 입력`: 최근 3개월 월매출을 기본으로 최대 12개월까지 입력하고 현재 현금, 월 필수비용, 기존 대출을 입력한다.
3. `현금 진단`: 선택 상권×업종의 보수·기준·회복 상황을 적용해 13주 현금, 안전현금 하회 주차, 6개월 현금·부채를 확인한다.
4. `대안과 실행`: 사용자 목표를 고르고 무대응과 정책·비용절감 대안 곡선을 동시에 비교한다. 카드·그래프 선택은 결과 강조만 바꾸며 초록색 `자세히 보기` 버튼을 눌렀을 때만 실행정보가 포함된 Popup을 연다.

서비스 설명 전용 화면, 검증 샘플 선택, 직접 충격률, Target A/B, P10/P50/P90, 내부 평가수치는 사용자 흐름에서 제거한다.

## 상권 지도

- 원본: `data/raw/서울시 상권분석서비스(영역-상권)` Shapefile, UTF-8, EPSG:5181
- 서비스 범위: 현행 상권목록과 일치하는 1,596개, 자치구 25개, 자치구·행정동 조합 398개
- 표시값: 공식 X·Y 중심좌표를 WGS84로 변환한 위·경도, `RELM_AR` 면적, `sqrt(면적/pi)` 반지름
- 지도 표현: 처음에는 코발트색 자치구 집계 원 25개만 표시하고, 자치구 선택 후 행정동 집계 원, 행정동 선택 후 작은 개별 상권 원으로 세분화한다. 모든 원은 OSM의 녹지·도로·수면 위에서도 경계가 읽히도록 짙은 청색 선과 흰 외곽 링을 사용한다. 개별 상권은 실제 폴리곤 대신 중심점과 면적 비례 반지름을 사용하며 원은 실제 경계가 아님을 표시한다.
- 상호작용: 자치구를 선택하면 해당 구의 행정동 원만 표시하고 그 범위로 확대한다. 지도를 다른 구 방향으로 옮겨 중심이 넘어가면 원을 그 구의 행정동으로 교체해 서울 전체 행정동을 한꺼번에 겹쳐 그리지 않는다. 개별 상권도 같은 방식으로 현재 지도 중심과 가장 가까운 행정동 범위만 표시한다. 지도 중심 기준으로 줌 13~14는 자치구, 15~16은 행정동, 17 이상은 개별 상권을 자동 선택하며 줌 12 이하에서는 서울 전체 자치구 단계로 복귀한다. 목록 선택과 지도 원 클릭은 해당 위치로 이동하며 단계 표시를 눌러 상위 수준으로도 돌아갈 수 있다.
- 상시 라벨·Hover·Popup: 자치구·행정동 원 안에는 지역명과 포함 상권 수를 항상 표시하고, 개별 원 안에는 상권명을 두 줄까지 표시한다. Hover·Popup은 전체 상권명·자치구·행정동·상권유형·면적과 다음 탐색 단계 안내를 제공한다.
- 검색: 상권 이름 검색은 자치구 선택보다 먼저 배치하며, 자치구·행정동 선택값과 관계없이 서울 전체 1,596개 상권을 대상으로 한다. 결과를 선택하면 해당 자치구·행정동과 지도 위치를 함께 갱신한다.
- 지도 타일 또는 JavaScript 라이브러리가 실패해도 자치구·상권 목록 선택은 유지한다.

## 재무 입력

업종은 서비스업종 코드의 상위 체계인 `CS1 외식업`, `CS2 서비스업`, `CS3 소매업` 대분류를 먼저 고른 뒤 세부 업종을 선택한다. 최근 월매출과 현재 현금·비용·대출은 화면에서 만원 단위로 받고 API 요청 전에 원 단위 정수로 변환한다. 최근 월매출은 3~12개 산술평균을 원 단위 반올림해 6개월 반복 매출로 사용한다. 매출은 매일·매주·월 1~10일·11~20일·21일~월말, 비용과 상환은 세 구간 중 하나를 선택한다. RE3 간편모드가 각 범주를 보수·기준·완화의 정확한 날짜 일정으로 변환하며 정책 비교는 기준 일정을 쓴다.

상세 입력은 UTF-8-SIG 한글 CSV를 제공한다. 거래내역은 `거래번호, 거래일, 구분, 금액(만원), 비용종류, 메모`, 대출은 `대출명, 잔액(만원), 연이율, 상환방식, 상환일, 만기일, 거치개월`을 쓴다. 기존 영문 컬럼과 한글 원 단위 `금액`, `잔액`도 계속 지원한다. CSV는 여러 달·분기의 실제 날짜를 받을 수 있지만 정책 대안 구성에는 간편 입력도 필요하다. 승인금액·지급일·동시수혜를 CSV만으로 추정하지 않기 때문이다.

## 상권환경 시나리오

`market_features_2025q4.parquet`에서 선택 상권×업종의 최신 197개 Feature를 찾고 동결된 RE5 LightGBM Quantile Artifact로 13주·6개월 하방·기준·회복 변화율을 추론한다. 화면에는 내부 Quantile 이름과 평가수치를 노출하지 않는다. 값은 상권×업종 전체의 전년 같은 기간 대비 매출환경 참고 변화율이며 개별 점포 매출 예측이 아니다. 조합 자료가 없거나 모델을 읽지 못하면 변화율 0%의 결정론적 Fallback을 사용하고 그 상태를 표시한다.

## 현금 진단과 대안 비교

- 13주 진단과 대안 카드의 무대응은 같은 선택 시나리오를 반영하므로 마지막 현금이 일치해야 한다.
- 안전현금은 향후 28일 필수비용과 대출상환금의 합이며 실제 일정에 따라 달라진다.
- 13주 그래프는 Y축 현금 잔액(만원), X축 주차, 0원 기준, 안전현금 영역을 표시한다.
- 대안 카드는 13주·6개월 현금, 신규부채, 월 최대상환, 무대응 대비 차이를 우선 표시한다.
- 총이자와 확인조건을 포함한 전체 표는 접어 두고 필요할 때 펼친다.
- 비교 그래프는 계산 가능한 모든 대안 곡선을 동시에 표시한다. 선택 대안은 초록색 굵은 선, 나머지는 회색 선이며 곡선 또는 범례를 누르면 선택 대안이 바뀐다.
- 대안 Popup은 핵심 수치, 먼저 확인할 조건, 신청기한, 준비서류, 지급 전 필요현금, 최소 신청금액, 문의처, 사이트명·순번으로 구분한 공식 링크를 한 화면에 보여준다. 닫기 버튼과 바깥 배경 클릭으로 닫히며, 별도 실행계획 섹션은 두지 않는다.
- 사용자 목표의 화면 명칭과 내부 결정론 정렬키를 분리한다. 목표를 바꾸면 실행 가능한 대안을 해당 정렬키 순서로 다시 배치하고, 카드마다 현재 목표의 판단값을 바꾸며, 상세 표에 현재 목표 순위를 표시한다. 같은 대안이 여러 목표에서 계속 1순위일 수 있으며 이는 화면 오류가 아니라 입력값과 자격 확인된 후보 수에 따른 결정론 결과다.
- 카드나 그래프에서 대안을 선택하면 상단 안내문은 목표 1순위에 고정되지 않고 현재 선택한 대안의 판단값, 1순위 여부, 13주 중 최저 현금, 자격·접수 상태, 해당 대안의 확인사항만 표시한다. 자격 확인 전 정책은 그래프 비교에는 남기되 추천 순위에서는 제외한다. AI는 이 순위를 만들거나 변경하지 않는다.

## AI와 개인정보

로컬 SQLite가 정책·버전·기준일로 공식·검토 문서를 검색한다. Luna는 검색 근거를 한국어로 설명할 뿐 금융계산, 자격판정, 정책 순위, 승인확률을 생성하지 않는다. `OPENAI_API_KEY`가 있을 때 질문과 검색 근거만 `store=false`로 전송하며 사업장·재무 입력은 전송하지 않는다. 키, DB, 모델, Fact-lock 가운데 하나가 실패해도 구조화 결과와 공식 링크는 유지한다. 요청 본문·CSV·질문은 서비스 DB나 검색 인덱스에 저장하지 않는다.

## 반응형·접근성

- 시스템 밝은·어두운 색상모드와 `prefers-reduced-motion`을 지원한다.
- 데스크톱은 입력 요약을 고정하고, 1,050px 이하에서는 숨긴다.
- 760px 이하에서는 모든 주요 카드와 입력을 한 열로 바꾸고 단계 탭만 자체 가로 스크롤한다.
- 390×844 검증에서 문서 전체 가로 넘침이 없어야 한다.
- 모든 입력은 Label, 키보드 Focus, 상태문구를 제공한다.
