# 버팀AI · 정책금융 영향 시뮬레이터

**정책자금을 이용하면 현금 부족이 해소될까? 그 뒤에 남는 부채는 얼마나 늘어날까?**

버팀AI는 서울 소상공인이 정책 이용 전후의 **13주 현금흐름과 6개월 부채 부담**을 같은 일정에서 비교하는 금융 AI 웹서비스입니다. 사업장 재무정보와 상권환경을 바탕으로 무대응, 비차입 지원, 대환, 신규 정책자금(융자)의 결과를 계산하고, 선택한 정책의 자격조건과 공식 신청정보를 확인하도록 돕습니다.

## 해결하려던 문제

지원금액과 금리만으로는 정책이 사업장의 현금 부족을 해결하는지 알기 어렵습니다. 지원금을 받기 전에 사업비를 먼저 지출해야 할 수도 있고, 신규 정책자금으로 당장의 현금을 확보해도 이후 부채와 상환 부담이 커질 수 있습니다.

버팀AI는 정책을 찾은 다음의 판단에 초점을 맞췄습니다. **아무 정책도 이용하지 않은 경우를 기준선으로 두고, 지급일·자부담·거치기간·상환 일정을 반영했을 때 무엇이 달라지는지** 보여줍니다.

| 확인할 질문 | 비교 지표 |
| --- | --- |
| 정책이 현금 부족 시점을 늦추는가? | 첫 현금 부족 주차 |
| 단기 운영기간이 끝날 때 현금이 얼마나 남는가? | 13주차 현금 |
| 현금 확보와 함께 부채가 얼마나 늘어나는가? | 6개월 뒤 남은 부채 |
| 가장 부담이 큰 달에 얼마를 갚아야 하는가? | 월 최대 상환액 |
| 만기까지 부담할 금융비용은 얼마인가? | 만기까지 총이자 |

## 대표 가상 사례

현재 현금 **100만 원**, 월매출 **350만 원**, 월 필수비용 **485만 원**, 기존 대출 **3,000만 원**인 가상 음식점을 비교했습니다. 기준일은 2026년 9월 1일이며, 아래 수치는 포트폴리오에 수록된 고정 사례입니다.

| 지표 | 무대응 | 비차입 지원 | 신규 정책자금(융자) |
| --- | ---: | ---: | ---: |
| 첫 현금 부족 시점 | 1주차 | 1주차 | 13주 안에 없음 |
| 13주차 현금 | -6,670,655원 | -7,420,655원 | 10,779,554원 |
| 6개월 뒤 남은 부채 | 27,049,182원 | 27,049,182원 | 44,609,140원 |
| 월 최대 상환액 | 791,803원 | 791,803원 | 828,386원 |
| 만기까지 총이자 | 9,300,006원 | 9,300,006원 | 10,635,291원 |

비차입 지원은 사업비 375만 원을 먼저 지출하고 300만 원을 돌려받는 조건입니다. 신규 부채는 없지만 자부담 때문에 13주차 현금이 무대응보다 **75만 원 감소**합니다. 신규 정책자금은 13주 안의 현금 부족을 해소하지만, 6개월 뒤 남은 부채가 **17,559,958원 증가**합니다.

이 사례는 지원 유형만으로 유불리를 판단하기 어려운 이유를 보여줍니다. 실제 사업장의 예측이나 정책 효과를 입증한 결과는 아닙니다.

![무대응과 정책 대안의 13주 현금흐름 비교 화면](https://max-ji64.github.io/projects/2026-finance-ai-challenge/images/05-cashflow-comparison.png)

## 사용자 흐름

회원가입 없이 **진단 → 비교 → 준비**의 세 단계로 이용합니다.

| 단계 | 사용자가 하는 일 | 서비스가 제공하는 결과 |
| --- | --- | --- |
| 진단 | 서울 상권·업종, 해결 목적, 최근 3~12개월 매출, 현금, 비용, 기존 대출과 유입·지출 시점 입력 | 무대응 현금흐름과 상권환경의 하방·기준·회복 범위 |
| 비교 | 제시된 정책 후보 최대 3개 중 비교 대상 선택 | 같은 일정에서 계산한 현금, 부채, 상환 부담과 조건부 안내 |
| 준비 | 선택한 정책의 자격조건에 답하고 신청정보 확인 | 입력 기준 적격 후보·부적격·추가 확인 필요 상태와 공식 신청 경로 |

해결 목적은 먼저 볼 지표와 정책 검토 순서를 바꿉니다. 자격조건, 정책 금액과 금융 계산 결과는 바꾸지 않습니다. 확인되지 않은 조건은 조건부로 표시하며, 최종 자격과 현재 접수 여부는 공식기관에서 확인하도록 연결합니다.

## 데이터와 계산 구조

### 상권환경 모델

서울시 상권분석서비스의 **공개자료 9종, 2021년 1분기~2025년 4분기** 자료를 상권·업종·분기 기준으로 구성했습니다. 추정매출, 점포, 상권 영역, 유동인구, 상권변화, 상주인구, 직장인구, 집객시설, 아파트 자료를 사용합니다.

LightGBM Quantile은 상권·업종 집계의 다음 1분기와 다음 2분기 합산 매출 증감률을 산출합니다. P10·P50·P90은 화면에서 **하방·기준·회복**으로 제시하며, 각각의 가정을 매출 유입 일정에 적용합니다.

이 범위는 개별 점포 매출의 확률이나 보장된 예측구간이 아닙니다. 13주 현금과 6개월 부채는 모델이 직접 예측하지 않고, 사용자 입력과 정책 일정을 반영한 금융 계산 엔진이 산출합니다.

### 동일한 기준선에서 정책 비교

```text
상권·업종 공개자료 → LightGBM Quantile → 매출환경 범위
                                              ↓
사용자 재무 입력 + 유입·지출 일정 → 무대응 기준선
                                              ↓
공식 정책 조건 → 지급·선지출·상환 일정 → 정책 적용 대안
                                              ↓
                      13주 현금 · 6개월 부채 · 상환 부담 비교
```

모든 대안은 같은 사업장 입력, 상권환경 범위와 계산 시작일을 사용합니다. 정책 조건은 지급, 자부담 지출, 신규 대출 실행, 원리금 상환처럼 날짜가 있는 금융 사건으로 변환합니다.

공고에서 확인되지 않은 금액이나 시점은 임의로 채우지 않습니다. 사용자가 확인한 가정으로 계산할 때는 조건부 결과로 구분합니다.

## AI와 금융 결정의 역할 분리

자연어를 해석하고 공고를 설명하는 기능과, 자격 및 금융 결과를 결정하는 기능을 분리했습니다.

| 구성 요소 | 담당 역할 |
| --- | --- |
| LightGBM Quantile | 상권·업종 집계의 매출환경 범위 산출 |
| 공식 규칙 엔진 | 검수한 공고 조건과 사용자 답변을 대조해 서비스 내 자격 상태 산출 |
| 금융 계산 엔진 | 현금·부채·원리금·이자와 정책 비교 결과 계산 |
| 생성형 AI | 동의받은 가정 문장의 구조화, 공식 공고 정리, 선택 정책에 관한 근거 기반 설명 |

공고 분석은 **신청 기간, 금융 조건, 신청 경로, 필요 서류, 문의처, 게시일**의 여섯 항목을 다룹니다. 근거가 없는 숫자나 조건은 결과에 반영하지 않고 공식 공고 확인으로 전환합니다. 생성형 AI가 응답하지 않아도 핵심 진단과 정책 비교를 제공할 수 있도록 구성했습니다.

재무 입력과 상담 대화는 서비스 데이터베이스에 장기 저장하지 않습니다. 외부 AI에는 재무 원장, 월매출, 현금, 비용, 대출과 금융 계산 결과를 보내지 않습니다. 외부 AI를 사용하는 기능은 별도 동의를 받으며, 공개 공고나 동의한 가정 문장, 금액·식별정보를 제거한 정책 질문으로 전송 범위를 제한합니다.

## 구현 결과와 검증 범위

FastAPI와 JavaScript 기반 웹서비스를 구현하고 Google Cloud Run에 배포했습니다. 기획서와 기능명세서를 작성했으며, 포트폴리오에는 외부 연결 없이 확인할 수 있는 정적 데모를 제공합니다. 현재 저장소의 서비스 진입점은 `v5.main:app`입니다.

대표 사례와 고정 입력 검증은 기능 흐름과 계산 일관성을 확인하는 근거입니다. 실제 소상공인의 사용성, 정책 신청 성과, 매출 개선이나 폐업 감소를 검증한 결과로 해석하지 않습니다. 상권환경 모델 역시 이후 분기의 독립 데이터로 추가 검증이 필요합니다.

서비스 범위는 정책 선택 전의 재무 비교와 신청 준비까지입니다. 개별 점포의 매출·폐업·승인 가능성 예측, 계좌·POS 자동 연동, 민감서류 업로드·OCR, 기관 전송과 자동 신청은 포함하지 않습니다.
