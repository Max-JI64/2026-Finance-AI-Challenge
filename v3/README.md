# 버팀AI V3

V2 정적 파일을 `v3/static`으로 복사한 뒤 그 복사본만 수정한 독립 서비스다. V2의 4단계 화면, 계층형 원 지도, 입력·차트·정책 UI는 유지한다. `app/`과 기존 `src/`를 수정하지 않으며, 검증된 V2 API와 금융 엔진을 호환 경로로 재사용한다.

복사 기준 해시는 `V2_BASELINE_SHA256.md`에 기록했다.

## 실행

```powershell
& 'C:\Program Files\Python313\python.exe' -m uvicorn v3.main:app --host 127.0.0.1 --port 8001
```

접속 주소: `http://127.0.0.1:8001`

## 경계

- 사용자 입력은 서버에 장기 저장하지 않는다.
- 정책 후보 검색은 동의 없이 외부 임베딩을 호출하지 않고 로컬 SQLite BM25를 사용한다.
- 외부 AI는 사용자가 행동 브리프 호출에 동의한 경우에만 기존 Fact Lock 경로를 사용한다.
- 상황 문장은 다섯 예시에서 시작해 수정할 수 있고, 사용자가 체크해 확인한 정확한 상권·업종·목표와 걱정 신호만 후속 입력·질문·행동계획에 반영한다. 금액은 문장에서 추정하지 않는다.
- 자격·현금·부채·순위는 기존 규칙·계산 엔진이 결정한다.
- 정책은 자동 선택하지 않으며 사용자가 직접 최대 3개를 고른다.
- 정책 확인 질문은 화면에 한 번에 하나만 보여준다. 최대 4개인 1차 묶음과 최대 3개인 2차 묶음 안에서는 답변 즉시 다음 질문으로 이동하고, 서버 재계산은 각 묶음이 끝날 때만 수행한다.
- What-if는 매출 증감률, 비용 절감액, 상권 시나리오, 비교 기준만 계산한다. 비용 상승은 Luna 호출 전에 한 번만 안내하고 종료하며, 불명확한 입력의 확인 질문도 최대 한 번만 허용한다.
- What-if 예시는 입력창 위에 항상 표시하며, 예시를 누르면 사용자가 수정할 수 있도록 입력창에만 채운다.
- V4의 알림·장기 기억·계좌 연동·자동 신청은 구현하지 않는다.
